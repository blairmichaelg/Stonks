# Stonks

Real-time stock tracking and portfolio visualization dashboard.

[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![React](https://img.shields.io/badge/React-20232A?logo=react&logoColor=61DAFB)](https://reactjs.org/)

## Overview

A responsive stock market dashboard for tracking portfolios and visualizing market data in real time. Built with TypeScript and React.

## Features

- Real-time stock price tracking
- Portfolio visualization and analytics
- Interactive charts and data views
- Responsive design for desktop and mobile

## Tech Stack

- **Frontend**: React, TypeScript
- **Styling**: CSS modules
- **Build**: Vite

## Setup

```bash
npm install
npm run dev
```
